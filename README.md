## Descripción del Proyecto
Logitarea es una aplicación desarrollada en Python que permite la administración de tareas pendientes. El sistema utiliza el patrón de diseño Modelo-Vista-Controlador (MVC) para separar la lógica de negocio de la interfaz de usuario, facilitando el mantenimiento y la escalabilidad del código.

## Características Técnicas
- Arquitectura: Modelo-Vista-Controlador (MVC).
- Interfaz Gráfica: Implementada con la librería Tkinter.
- Estructura de Datos: Uso de listas enlazadas simples para el manejo dinámico de la información.

## Estructura de Carpetas
- /src: Contiene el código fuente del proyecto.
- /controllers: Lógica de control y eventos.
- /models: Definición de las estructuras de datos y lógica de negocio.
- /views: Definición de la interfaz gráfica de usuario.
- main.py: Punto de entrada principal de la aplicación.

## Instrucciones de Ejecución

Para ejecutar la aplicación en un entorno local, siga los siguientes pasos:

1. Prerrequisitos:
   Asegúrese de tener instalado Python 3.x en su sistema operativo.

2. Descarga del código:
   Descargue el repositorio en formato ZIP y extraiga el contenido en una carpeta local.

3. Instalación de dependencias (opcional):
   Si el proyecto requiere librerías externas listadas en el archivo de requerimientos, ejecute:
   pip install -r requirements.txt

4. Inicio de la aplicación:
   Abra una terminal dentro de la carpeta del proyecto y ejecute el siguiente comando:
   python main.py
